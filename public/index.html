그룹 선택

좌측에서 그룹을 선택하세요.

관리자로 임명할 회원 검색

이름, 사용자명(@username), Telegram ID로 검색할 수 있습니다. 기존 수집 회원은 이름·ID로 검색하고, @사용자명은 텔레그램에서 직접 조회할 수 있습니다.

추가 조회 기능 확인 중

추가 조회 기능에는 Railway에 TELEGRAM_API_ID와 TELEGRAM_API_HASH가 필요합니다. 텔레그램 조회 결과는 해당 그룹 소속 확인 후 선택됩니다. 전체 회원을 항상 불러올 수 있는 것은 아닙니다.
